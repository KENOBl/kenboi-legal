Privacy Policy

Application: Social Worker (internal tool for Kenboi cafe)
Effective date: 2026-06-08
Contact: itwydmuch@gmail.com

1. Overview

Social Worker is a private, single-business automation tool used by the owner of Kenboi cafe to schedule and publish content (photos, videos) to the business's own social media accounts on Instagram, Facebook, and TikTok. The application is not offered as a service to other users.

2. Data we collect from TikTok

When the application is connected to a TikTok account via OAuth, we receive and store: Open ID, Union ID, display name, avatar URL, access and refresh tokens, and metadata of videos we ourselves publish (title, description, status, video ID). We do not access data of other TikTok users, comments, followers, or direct messages.

3. How we use the data

Authenticating with TikTok's Content Posting API, publishing videos we have created ourselves to the connected account, and storing publication history for internal record-keeping.

4. Storage and security

Access tokens are stored in encrypted environment variables on the application server. Profile information and publication history are stored in a local SQLite database accessible only to the application owner. No data is shared with third parties.

5. Data retention

Data is retained for as long as the application is in use. The owner can revoke TikTok access at any time via TikTok app settings.

6. User rights (GDPR)

This is a single-user tool operated by the business owner for the business's own accounts. There are no third-party users whose rights apply. The owner has full control over all stored data.

7. Third-party services

This application interacts with TikTok Content Posting API, Meta Graph API for Instagram and Facebook, and Cloudinary for temporary media hosting. These services have their own privacy policies.

8. Contact

For questions regarding this policy, contact: itwydmuch@gmail.com
